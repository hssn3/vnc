# VNC Link — لینک ریموت دسکتاپ با Cloudflare (+ ربات تلگرام)

یک برنامهٔ **پرتابل ویندوز** با رابط گرافیکی مدرن: اجرا می‌کنید، رمز ورود می‌گذارید،
دکمهٔ «ایجاد لینک» را می‌زنید و یک لینک `https://….trycloudflare.com` تحویل می‌گیرید.
طرف مقابل فقط با **مرورگر** لینک را باز می‌کند و دسکتاپ را **تمام‌صفحه و با کمی زوم‌اوت**
می‌بیند. لینک و رمز به‌صورت خودکار به **ربات تلگرام** شما ارسال می‌شود.

نسخهٔ فعلی: **1.2.0** — همهٔ پیش‌نیازها داخل یک پوشه (بدون نصب، بدون admin).

---

## ۱) چه چیزهایی در ۱.۲ اضافه/عوض شد

| مورد | توضیح |
|---|---|
| صفحهٔ نمایش شیشه‌ای | پیش‌نمایش دسکتاپ با پنل‌های glass (blur)، انیمیشن ورود/اتصال، فونت‌های بزرگ‌تر و نوار ابزار شناور |
| تمام‌صفحه + زوم‌اوت | دسکتاپ با نسبت درست داخل مرورگر جا می‌شود (حاشیهٔ ~۳٪) و دکمهٔ ⛶ تمام‌صفحهٔ واقعی دارد |
| تاریخچهٔ لینک‌ها | هر لینک ساخته‌شده در `links.json` ذخیره و در جدول برنامه لیست می‌شود (کپی/باز کردن/ارسال به تلگرام/پاک کردن) |
| پایش وضعیت | هر ۱۰ ثانیه لینک چک می‌شود: «آنلاین + زمان پاسخ + ساعت آخرین بررسی» یا «آفلاین» + مدت فعال بودن |
| لینک بدون رمز | اگر رمز را خالی بگذارید خطا نمی‌دهد؛ یک کلید تصادفی ساخته و **داخل خود لینک** می‌نشیند تا بدون پرسیدن رمز باز شود |
| دکمهٔ توقف | «توقف» سرور VNC، پل noVNC، تونل و لینک را کامل می‌بندد و تنظیمات قبلی رجیستری را برمی‌گرداند |
| همه‌چیز در یک پوشه | نسخهٔ onedir: پایتون + cloudflared + noVNC + TightVNC داخل `_internal`؛ داده‌ها کنار EXE |

## ۲) نحوهٔ کار

```
مرورگر طرف مقابل ──HTTPS/WSS──> تونل Cloudflare ──> websockify + noVNC (127.0.0.1:6080)
                                                        │ WebSocket
                                                        ▼
                                                TightVNC (127.0.0.1:5900)
                                                احراز هویت با رمز VNC
```

1. سرور TightVNC فقط روی `127.0.0.1:5900` بالا می‌آید (از شبکهٔ محلی قابل دسترسی نیست).
2. رمز به فرمت استاندارد VNC در `HKCU\Software\TightVNC\Server` نوشته می‌شود و با «توقف» برمی‌گردد.
3. websockify صفحهٔ `index.html` (نمایشگر سفارشی) و پل WebSocket را روی `127.0.0.1:6080` سرو می‌کند.
4. `cloudflared tunnel --url` یک لینک موقت عمومی می‌سازد.
5. اگر توکن ربات تنظیم شده باشد، لینک + رمز به تلگرام می‌رود.

هیچ پورتی روی فایروال باز نمی‌شود؛ همه‌چیز از طریق اتصال خروجی است.

## ۳) اجرا (کاربر نهایی)

### اجرا از داخل همین پوشهٔ پروژه

1. فایل **`Run-VNC-Link.bat`** را در ریشهٔ پروژه دوبار کلیک کن.
2. برنامه از `dist\VNC-Link\VNC-Link.exe` بالا می‌آید (همهٔ پیش‌نیازها در همان پوشه است).

> اگر خواستید پوشه را جای دیگری ببرید، کل پوشهٔ `dist\VNC-Link` را کامل کپی کنید
> (فایل `VNC-Link.exe` تنها کافی نیست؛ پوشهٔ `_internal` همراه آن لازم است).

### مراحل استفاده

1. پوشهٔ `VNC-Link-1.2.0` را هرجای ویندوز کپی کنید و `VNC-Link.exe` را اجرا کنید.
2. رمز ورود بگذارید: **۱ تا ۸ کاراکتر انگلیسی/عدد** — یا خالی بگذارید تا بدون رمز باز شود.
3. «ایجاد لینک» → ۵ تا ۳۰ ثانیه صبر کنید.
4. لینک در کارت «لینک فعلی» ظاهر می‌شود؛ «کپی» یا «باز کردن».
5. وضعیت همان‌جا پایش می‌شود: 🟢 آنلاین / 🔴 آفلاین + مدت فعال بودن.

> لینک‌های `trycloudflare` موقت‌اند: با «توقف» یا بستن برنامه از کار می‌افتند.
> تاریخچه در `links.json` می‌ماند تا لینک‌های قبلی را ببینید/کپی کنید.

## ۴) ربات تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید → `/newbot` → توکن بگیرید.
2. توکن را در فیلد «توکن ربات» بچسبانید.
3. به ربات خودتان یک پیام (`/start`) بدهید.
4. **«دریافت خودکار»** چت‌آی‌دی را پر می‌کند.
5. **«تست اتصال»** → باید بنویسد «اتصال برقرار است: ربات @your_bot».
6. «ارسال خودکار لینک» را تیک بزنید و **«ذخیرهٔ تنظیمات»** را بزنید.

پیام ارسالی شامل لینک، رمز (یا «بدون رمز») و دکمهٔ «اتصال به دسکتاپ» است.

## ۵) فایل‌های داده (همه داخل پوشهٔ برنامه)

| فایل | کار |
|---|---|
| `settings.json` | توکن ربات، چت‌آی‌دی، رمز (اختیاری)، تنظیم ارسال خودکار |
| `links.json` | تاریخچهٔ لینک‌ها با زمان ساخت/بستن و رمز هر لینک |
| `vnc-link.log` | گزارش متنی اجرا |

> `settings.json` و `links.json` متن‌ساده‌اند و توکن/رمز داخلشان است؛ پوشه را دست کسی نسپارید.

## ۶) نکات امنیتی

- لینک عمومی است؛ هر کس لینک (و رمز) را داشته باشد کنترل دسکتاپ را می‌گیرد.
- در حالت «بدون رمز»، کلید تصادفی داخل خود لینک است — یعنی لینک = کلید. آن را فقط برای فرد مورد اعتماد بفرستید.
- برنامه چیزی را پنهان نمی‌کند: تا خودتان «ایجاد لینک» را نزنید هیچ سرویسی بالا نمی‌آید و با «توقف» همه‌چیز بسته می‌شود.
- `VNC-Link.exe` ممکن است توسط Windows Defender «مشکوک» علامت بخورد (PyInstaller + سرور VNC + تونل)؛ برای پوشه استثنا بگذارید.
- فقط روی سیستم‌هایی استفاده کنید که مالک آن هستید یا اجازهٔ دسترسی دارید.

## ۷) ساخت از سورس

پیش‌نیاز: ویندوز ۱۰/۱۱، پایتون ۳.۱۲ **با tkinter** (نسخهٔ رسمی python.org).

```bat
pip install -r requirements.txt
python scripts\prepare_assets.py   :: دانلود cloudflared (novnc و tvnserver در ریپو هستند)
python scripts\build.py            :: ساخت dist\VNC-Link\  (پوشهٔ کامل و پرتابل)
```

## ۸) تست‌ها و نتیجه

```bat
python tests\test_telegram.py                       :: تلگرام + settings + تاریخچه (با سرور ماک)
python tests\test_e2e.py                            :: سورس: تونل + نمایشگر + RFB با رمز درست/غلط
python tests\test_e2e.py --nopass                   :: حالت بدون رمز (کلید داخل لینک)
python tests\test_e2e.py --exe dist\VNC-Link\VNC-Link.exe   :: همان تست‌ها روی EXE نهایی
python tests\probe_noauth.py                        :: بررسی بایت‌به‌بایت حالت None-auth
```

آخرین اجرای تست‌ها:

- `test_telegram.py` → **۱۴/۱۴** پاس (getMe، getUpdates، sendMessage، دکمهٔ inline، خطای 403، توکن بدشکل، round-trip تنظیمات، تاریخچه: افزودن/بستن/پاک کردن).
- `test_e2e.py` روی سورس و روی EXE → تونل ساخته شد، صفحهٔ نمایشگر سرو شد، ورود با رمز درست ✅ (۱۹۲۰×۱۰۸۰ + فریم‌بافر از روی تونل عمومی)، رمز غلط رد شد ✅، خروج تمیز و آزادسازی پورت‌ها.
- `test_e2e.py --nopass` → لینک حاوی کلید خودکار، ورود بدون پرسش رمز ✅، رمز اشتباه رد شد ✅.
- بررسی مرورگر واقعی (Chrome): پنل شیشه‌ای ورود، اتصال با رمز، نمایش دسکتاپ ۱۹۲۰×۱۰۸۰ با مقیاس ۱۴۷۵×۸۳۰ در پنجرهٔ ۱۶۰۰×۹۰۰، نوار ابزار شیشه‌ای با وضعیت «متصل — کنترل فعال است».
- بستهٔ ZIP روی دسکتاپ: باز شدن، اجرا و سرو شدن نمایشگر (۱۵٬۱۷۷ بایت) تأیید شد.

## ۹) عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| «تونل Cloudflare ساخته نشد» | اینترنت/فیلترینگ؛ `trycloudflare.com` و `api.telegram.org` باید در دسترس باشند |
| خطای 530 یا صفحهٔ سفید در ثانیه‌های اول | DNS تونل تازه چند ثانیه زمان می‌برد؛ رفرش کنید |
| «پورت 5900 اشغال است» | یک VNC دیگر در حال اجراست؛ ببندید |
| وضعیت «آفلاین» می‌شود | لینک با «توقف»/بستن برنامه بسته شده یا اینترنت قطع است |
| تلگرام: «چت پیدا نشد» | یک بار در ربات `/start` بزنید، بعد «دریافت خودکار» |
| تلگرام: 401 | توکن باطل شده؛ از BotFather توکن جدید بگیرید |
