# VNC Link — لینک ریموت دسکتاپ با Cloudflare (+ ربات تلگرام)

یک برنامهٔ **پرتابل ویندوز** با رابط گرافیکی: اجرا می‌کنید، رمز ورود تعریف می‌کنید،
دکمهٔ «ایجاد لینک» را می‌زنید و یک لینک `https://….trycloudflare.com` تحویل می‌گیرید.
طرف مقابل فقط با **مرورگر** (بدون نصب هیچ نرم‌افزاری) لینک را باز می‌کند، رمز را می‌زند و
دسکتاپ را می‌بیند/کنترل می‌کند. لینک و رمز به‌صورت خودکار به **ربات تلگرام** شما ارسال می‌شود.

A portable single-file Windows GUI app that shares this desktop through a
password-protected Cloudflare Quick Tunnel (noVNC in the browser) and delivers
the link + password to your own Telegram bot.

نسخهٔ فعلی: **1.1.0**

---

## ۱) نحوهٔ کار

```
مرورگر طرف مقابل ──HTTPS/WSS──> تونل Cloudflare ──> websockify + noVNC (127.0.0.1:6080)
                                                        │ WebSocket
                                                        ▼
                                                TightVNC (127.0.0.1:5900)
                                                احراز هویت با رمز VNC
```

1. سرور TightVNC فقط روی `127.0.0.1:5900` بالا می‌آید (از شبکهٔ محلی قابل دسترسی نیست).
2. رمز شما به فرمت استاندارد VNC در `HKCU\Software\TightVNC\Server` نوشته می‌شود و
   هنگام «توقف» تنظیمات قبلی سیستم برمی‌گردد.
3. noVNC + websockify روی `127.0.0.1:6080` سرو می‌شود.
4. `cloudflared tunnel --url` یک لینک موقت عمومی می‌سازد.
5. اگر توکن ربات تنظیم شده باشد، لینک + رمز به تلگرام ارسال می‌شود.

هیچ پورتی روی فایروال باز نمی‌شود؛ همه‌چیز از طریق اتصال خروجی (outbound) کار می‌کند.
**هیچ نصبی لازم نیست**: cloudflared، noVNC و TightVNC داخل خود فایل اجرایی هستند.

## ۲) اجرا (کاربر نهایی)

1. فایل `VNC-Link.exe` را هرجای ویندوز کپی کنید و اجرا کنید (نیازی به نصب نیست، admin هم لازم نیست).
2. رمز عبور بگذارید: **۱ تا ۸ کاراکتر انگلیسی/عدد** (محدودیت پروتکل VNC) — دکمهٔ «تصادفی» هم هست.
3. «ایجاد لینک» را بزنید؛ ۵ تا ۳۰ ثانیه صبر کنید.
4. لینک در کادر «لینک اشتراک» ظاهر می‌شود؛ «کپی» یا «باز کردن».
5. طرف مقابل لینک را در مرورگر باز می‌کند، رمز را وارد می‌کند و دسکتاپ را می‌بیند.

> لینک‌های `trycloudflare` موقت‌اند: با «توقف» یا بستن برنامه از کار می‌افتند.
> هر بار اجرا، یک لینک تازه ساخته می‌شود.

## ۳) اتصال ربات تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید → `/newbot` → یک نام و یوزرنیم بدهید.
2. توکنی مثل `123456789:AAE...` می‌گیرید؛ آن را در فیلد «توکن ربات» بچسبانید.
3. به ربات خودتان یک پیام بدهید (`/start`) تا چت‌آی‌دی شناخته شود.
4. دکمهٔ **«دریافت خودکار»** چت‌آی‌دی را پر می‌کند (اگر خالی است).
5. **«تست اتصال»** → باید بنویسد: «اتصال برقرار است: ربات @your_bot».
6. گزینهٔ «ارسال خودکار لینک پس از ساخت» را تیک بزنید و **«ذخیره تنظیمات»** را بزنید.

از این پس با هر «ایجاد لینک»، پیامی شامل لینک + رمز + دکمهٔ «اتصال به دسکتاپ» به تلگرام می‌آید.
دکمهٔ «ارسال به تلگرام» هم دستی همان پیام را می‌فرستد.

## ۴) ذخیرهٔ تنظیمات

فایل `settings.json` **کنار خود فایل اجرایی** ساخته می‌شود (پرتابل: با کپی پوشه/فایل، تنظیمات هم می‌رود).
اگر مسیر قابل نوشتن نبود، به `%LOCALAPPDATA%\VNC-Link\settings.json` می‌رود.

```json
{
  "bot_token": "123456789:AAE...",
  "chat_id": "123456789",
  "auto_send": true,
  "remember_password": true,
  "password": "Abc12345",
  "ws_port": 6080
}
```

> این فایل متن‌ساده است و توکن ربات داخلش ذخیره می‌شود؛ فایل را جایی کپی نکنید که دست دیگری باشد.

## ۵) نکات امنیتی (مهم)

- لینک عمومی است؛ هر کسی که لینک **و** رمز را داشته باشد کنترل دسکتاپ را می‌گیرد. رمز را جدا از لینک بفرستید.
- احراز هویت VNC ضعیف است (رمز ۸ کاراکتری + کانال TLS کلادفلر). برای کارهای حساس از VPN استفاده کنید.
- برنامه هیچ‌جا اجرا نمی‌شود مگر خودتان اجرا و «ایجاد لینک» را بزنید؛ با «توقف» یا بستن پنجره همه‌چیز بسته می‌شود.
- فایل `VNC-Link.exe` (چون PyInstaller + سرور VNC + تونل است) ممکن است توسط Windows Defender
  یا آنتی‌ویروس‌ها «مشکوک» علامت بخورد؛ در صورت هشدار، برای همان فایل استثنا (Exclusion) تعریف کنید.
- فقط روی سیستم‌هایی استفاده کنید که مالک آن هستید یا اجازهٔ دسترسی دارید.

## ۶) ساخت از سورس

پیش‌نیاز: ویندوز ۱۰/۱۱، پایتون ۳.۱۲ **با tkinter** (نسخهٔ رسمی python.org؛ نسخهٔ فروشگاهی/embedded بدون tkinter است).

```bat
pip install -r requirements.txt
python scripts\prepare_assets.py   :: دانلود cloudflared (novnc و tvnserver در ریپو هستند)
python scripts\build.py            :: ساخت dist\VNC-Link.exe (تک‌فایل، پرتابل)
```

## ۷) تست

```bat
python tests\test_telegram.py                  :: تست واحد تلگرام + settings با سرور ماک (بدون توکن واقعی)
python tests\test_e2e.py                       :: اجرای سورس + تونل عمومی + noVNC + RFB با رمز درست/غلط
python tests\test_e2e.py --exe dist\VNC-Link.exe  :: همان تست‌ها روی فایل اجرایی نهایی
```

آخرین نتیجهٔ تست (این ماشین، ویندوز Server 2025 / 1920×1080):

- `test_telegram.py` → ۸/۸ پاس (getMe، getUpdates، sendMessage، دکمهٔ inline، خطای 403، توکن بدشکل، round-trip تنظیمات)
- `test_e2e.py` (سورس و EXE) → تونل ساخته شد، صفحهٔ noVNC سرو شد (۱۷۸۱۰ بایت)،
  ورود با رمز درست موفق (دسکتاپ ۱۹۲۰×۱۰۸۰ + فریم‌بافر از روی تونل عمومی)، رمز غلط رد شد، خروج تمیز و آزادسازی پورت‌ها.

## ۸) عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| «تونل Cloudflare ساخته نشد» | اینترنت/فیلترینگ؛ `trycloudflare.com` و `api.telegram.org` باید در دسترس باشند |
| خطای 530 از کلادفلر | چند ثانیه صبر کنید و صفحه را رفرش کنید (اولین اتصال DNS تونل تازه زمان می‌برد) |
| «پورت 5900 اشغال است» | یک سرور VNC دیگر در حال اجراست؛ ببندید یا ری‌استارت کنید |
| تلگرام: «چت پیدا نشد» | یک بار در ربات `/start` بزنید، بعد «دریافت خودکار» |
| تلگرام: 401 | توکن باطل شده؛ از BotFather توکن جدید بگیرید |
| صفحهٔ سیاه در مرورگر | رمز اشتباه است یا سرور VNC بسته شده؛ «توقف» و دوباره «ایجاد لینک» |
